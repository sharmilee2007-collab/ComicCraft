# ComicCraft

ComicCraft is a browser-based comic draft generator.

## Features
- Story prompt input
- Main character, setting, tone, and art-style selection
- 5-panel comic preview
- PDF export
- Responsive design
- Works as a simple static HTML project

## Run
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Enter a story prompt and click **Generate Comic**.
4. Use **Download Your Comic as PDF** to export the result.

## Project Files
- `index.html` — page structure
- `style.css` — design and responsive styling
- `script.js` — comic generation, preview, and PDF export

## Note
The project uses the jsPDF CDN and Google Fonts, so those external resources require an internet connection when loading the page.
